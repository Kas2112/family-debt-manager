# 💰 Family Debt Manager

A complete web-based Family Debt Management System with multi-user support, PWA capabilities, and advanced financial tracking features.

## 🎯 Features

### Core Features
- ✅ **Multi-User Authentication** - Each family member has their own account
- ✅ **User-Specific Debts** - Track debts separately per user
- ✅ **Admin Dashboard** - Admin can view all family debts
- ✅ **PWA Support** - Install as an app on your phone
- ✅ **Offline Mode** - Works without internet connection
- ✅ **Naira Currency** - Nigerian Naira (₦) support

### Financial Tools
- 📊 **Analytics Dashboard** - Charts and visualizations (pie, bar, line charts)
- 📈 **Payoff Calculator** - See when you'll be debt-free
- 🔔 **Payment Reminders** - Get notified before payments are due
- 📥 **CSV Export** - Export debt data to Excel/CSV
- 💡 **Debt Strategies** - Avalanche and Snowball methods

### User Experience
- 📱 **Mobile Responsive** - Works on all devices
- 🌙 **Dark Mode Ready** - (Coming soon)
- 🔐 **Secure Passwords** - Password hashing with bcrypt
- 🎨 **Modern UI** - Clean and intuitive design
